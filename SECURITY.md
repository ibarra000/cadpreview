# Security policy

cadpreview parses untrusted files, so memory-safety bugs, crashes, hangs and excessive memory
use on crafted input are all security issues.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's
[private vulnerability reporting](https://github.com/ibarra000/cadpreview/security/advisories/new),
not in public issues. Include the version, the platform, and if possible a minimal input file
that reproduces the problem. Synthetic or self-made inputs only, please: do not send
confidential CAD files.

You can expect an acknowledgement within a week. Fixes are released as patch versions and
credited in the changelog unless you prefer otherwise.

## Supported versions

Only the latest release receives security fixes.
