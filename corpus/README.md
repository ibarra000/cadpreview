# Test corpus

Sample files used to measure how well cadpreview renders each format, plus small synthetic
fixtures. `manifest.csv` lists every file and where it came from; `tools/corpus.py validate`
checks it and runs in CI.

## Layout

- `files/<format>/...`: real CAD files, stored with Git LFS (see `.gitattributes`).
- `synthetic/...`: fixtures generated by our own tools or written by hand from a public
  specification. Stored as ordinary Git files.

## Who may add files

Only clean files are accepted (see `notes/README.md`, rule 5):

- **self-made**: you modelled the part yourself in software you hold a license for, and you
  agree to publish the file under the license you put in the manifest (CC0-1.0 or CC-BY-4.0 are
  preferred). Do not add customer, employer or third-party models.
- **open-license**: the file is published by its author under an explicit open license; put the
  license and the URL in the manifest.
- **synthetic**: generated by our code or written from a public spec; put the generator or the
  spec section in `source`. Synthetic files never count toward a format's success rate.

Never add encrypted, password-protected, or confidential files.

## Manifest columns

| Column | Meaning |
|---|---|
| path | Relative to `corpus/`; starts with `files/` or `synthetic/` |
| format | Expected format id (`dwg`, `dxf`, `solidworks-part`, ...; `unknown` for negatives) |
| software | Application and version that wrote the file, e.g. "AutoCAD 2018" |
| file_version | Version recorded inside the file, if known |
| size_bytes, sha256 | Of the real content (for LFS files, of the object, not the pointer) |
| origin | `self-made`, `open-license`, or `synthetic` |
| contributor | Who made or contributed the file |
| license | SPDX expression for the file itself |
| source | URL (open-license), or generator / spec section (synthetic) |
| date_added | YYYY-MM-DD |
| notes | Anything else, e.g. what the model shows |

Keep at least three software versions per format, so each major version can be treated as its
own sub-format.

## Running the corpus

```sh
python tools/corpus.py run --cli build/win-release/bin/cadpreview.exe --tier 0 --tier 1 --tier 5
```

Results go to `build/corpus-run/<timestamp>/` (`results.jsonl` and `summary.md`). The command
fails if any file crashes the CLI or times out.

## Git LFS quota

Free GitHub accounts get a limited amount of LFS storage and bandwidth, and CI checkouts and
forks count against the repository owner. Real files are fetched only by the jobs that need
them. If the corpus grows large, move it to a separate download.
